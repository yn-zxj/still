# 自行管理课程

在设置开启“休息课程”后，侧栏出现课程库，休息提醒中才会推荐已添加的短课程。默认关闭；关闭不会删除资料或视频。

## 添加与编辑

- **本地视频**：选择 Mac 上的视频，保存时复制到应用课程目录，移动原文件后仍可播放。
- **链接导入**：填写 HTTPS 视频直链或网页地址，由应用自动判断。直接媒体保持原有边看边缓存与后续离线播放；无法解析为完整单文件视频的网页在独立的非持久化网页视图播放，可选择在浏览器打开。网页的登录、广告、清晰度、地区或播放限制由来源网站决定。退出播放页会停止网页；不缓存网页视频、不伪造课程完成记录。提醒里选择网页课程会终止普通休息倒计时。

只有课程名称和播放来源必填。展示时长用于列表和推荐；原生视频实际时长由播放器读取。简介、封面、准备、身体反应、建议与动作均可选；未填写的内容不显示。动作编辑器每行填写“名称 | 次数或时长”。修改动作会重建该动作表；只改标题/说明会保留原 JSON 的阶段和动作图片。

编辑页底部可以删除课程，确认后只移除目录条目，已复制的本地媒体保留，以免误删原资料；正在播放的课程会停止并卸载。课程封面右键也可编辑或移除。跟练期间先结束播放再编辑或导入。

原生视频进度条支持点击或拖动跳转；视频区域获得键盘焦点后，`←` / `→` 前后 5 秒，空格播放或暂停。滚轮继续滚动课程页面，不改变播放进度。跳过的区段不计入连续跟练时间。

## JSON

“导入 / 导出”支持 JSON 文件或含 courses.json 的文件夹。导入合并库，相同 id 更新条目，其他条目保留；不会自动获取原平台目录或调用平台私有接口。动作图和视频文件与 JSON 放在同一目录，文件名不可包含路径。资源导入时重命名，避免重名文件覆盖其他课程。验证失败不替换现有库。

支持 JSON 数组、单课程对象、或包成 JSON 字符串的内容。最小格式如下：

```json
{
  "id": "my-course",
  "title": "我的课程",
  "media": { "filename": "lesson.mp4" }
}
```

默认展示时长为 5 分钟；schemaVersion 默认 1，source 默认“自行添加”，actions 默认空。使用 media.url 表示视频直链，media.webpage 表示网页地址。完整自制示例见 examples/course-template.json，示例地址需要替换。

导出会新建备份文件夹，保存 JSON 和当前条目引用的本地媒体；远程视频和图片只保存链接，不打包后台缓存。导出的文件夹可以重新导入，地址失效后需要自行更新。

## 第三方资料边界

安装包和源码不包含 Keep/OPPO/B站课程列表、媒体、原文或访问凭据。现有个人课程继续留在本机；桌面另存个人 JSON 备份，不进入 Git。参考接口 JSON 仅作个人研究记录，不能据此保证匿名可用、长期可用或再分发权利。

## 链接识别与解析组件

在添加/编辑页填写 HTTPS 地址后点“识别链接”：自动填入空白的标题、封面、简介与展示时长。已有内容不会被静默覆盖；“使用识别信息”可采用新识别结果。封面提供预览。实际视频时长仍由播放器读取，动作、准备和练习建议不由网页简介臆造。

- **通用解析**使用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)，优先找应用私有目录、~/.local/bin、Homebrew 的已安装版本。未安装时可在表单点击“安装通用解析组件”，从官方 stable Release 下载 universal `yt-dlp_macos`，核对 SHA2-256SUMS、文件大小、版本后保存到 Application Support/Still/VideoParser/yt-dlp（0700）。无需 Python、npm 或管理员权限；支持同位置更新。不将该可执行文件打进息间安装包。yt-dlp 源码 Unlicense，官方打包可执行文件含 GPLv3+ 等依赖，详见其上游许可证说明。
- **B站适配**参考并移植 [ucmao/media-parser](https://github.com/ucmao/media-parser) 的 MIT BilibiliParser，固定研究来源提交 `d23f190192743efe5cc418c647d53b1bc7a29962`。只包含普通公开视频的元信息与单文件 MP4 请求流程，不包含该项目的 SaaS、代理池、账号系统或其他平台解析器。保留 Copyright 和 MIT 许可到安装包 ThirdPartyNotices.txt。B站这一路不依赖通用组件。
- 原生播放只选取含画面及声音的单文件 MP4，排除 DRM 和 DASH 音画分离结果；分离流保留网页播放，不把无声视频当作成功。B站分段视频也不截取第一段冒充整片。
- 原网页保存在 `media.originalPage`，原生播放前重新解析临时 URL；Cookie/Authorization 不保存、不导出、不从浏览器读取。必要的 Referer/User-Agent/Origin 只在当前播放内存使用。AVURLAsset 使用 HTTPHeaderFields 选项传递这些请求头，该选项的跨系统稳定性仍需真实 macOS 13/14 播放验证。
- 此版本经解析得到的临时媒体不自动缓存；本地视频与用户输入的普通直链仍支持原缓存。解析失败可保留网页课程；原生加载失败提供“原网页”入口。网络/地区/平台改变仍可能导致失败，不能以支持网站清单视为逐站验收。
