# 多显示器提醒与简洁提醒

0.7.0 build 19：全屏、迷你和简洁提醒都在每块逻辑显示器展示。系统通知由 macOS 管理，不创建多份系统通知。

- 窗口使用各屏的全局坐标和 visibleFrame 定位，不使用 NSWindow.center()，覆盖负坐标、上下排列、不同尺寸及菜单栏/Dock 留白。
- 提醒共用 AppModel/UsageEngine 的正式倒计时；不是每个屏幕分别开始一次休息。关闭任何一块屏幕上的提醒，会同步收起所有提醒，倒计时仍按现有规则继续，结束后不会重新弹出简洁提醒。
- 迷你/全屏中点击课程，只保留该屏幕上的窗口，并使用一个播放器和一份声音；返回推荐列表恢复全部屏幕提醒。简洁提醒保持只有文字、时间和关闭按钮，不放课程入口。
- “结束跟练”现在通过返回提醒的状态转换停止播放，并恢复正在进行的休息倒计时；“完成并关闭”和右上角收起仍保留显式关闭行为。
- 显示器变化重新协调窗口，不调用 present 重新创建休息、重选推荐或重置预览倒计时。播放屏幕断开时，将原窗口及原播放器移到剩余屏幕，保留进度和暂停状态；没有可用屏幕时隐藏并暂停。
- 简洁提醒是顶部居中的半透明胶囊，高 50pt，宽度随文字变化并限制在本屏内；长文截断，倒计时和关闭按钮保留。浅深色沿用应用主题。正式打开立即倒计时，结束自动收起；预览单独计时，不写真实休息记录。

测试新增 5 项：三屏提醒/单屏训练路由、断开后的单屏接管/空屏列表、负坐标及垂直排列居中、横幅顶部定位及长文限宽、全屏和小屏跟练尺寸约束。已有设置持久化测试覆盖新增 simple 枚举。

当前机器实际接入内置 Color LCD 与 Mi Monitor。用户已在正常应用中确认两块屏都有简洁横幅、倒计时一致；正常应用课堂跟练结束后也已验证提醒恢复。自动化仍不能证明真实拔插时序、全部 Spaces、独占全屏或混合缩放的每一种组合均通过。正常应用的视觉与操作验收另记 PROJECT_STATUS.md。
