## 自动检测体验修复

- 移除持续运行的 ScreenCaptureKit 屏幕采集流，修复打开应用后 macOS 左上角采集提示遮挡关闭、缩放等窗口控件的问题。
- 自动检测改用键鼠活动、可授权键盘辅助和无需额外权限的 CoreAudio 媒体播放状态融合。
- 设置页把“画面变化”替换为“媒体播放”，实时显示是否检测到系统音频播放。
- 不请求屏幕录制权限，不读取屏幕内容、窗口标题、网页地址或音频样本。
- 锁屏、息屏、休眠和会话离开继续优先停止累计，键盘辅助仍只记录活动发生时间。

## 已知边界

- 静音视频、无声动画和静态阅读超过空闲阈值后仍依赖键鼠活动。
- 系统持续播放音频但无人观看时可能延长计时；媒体设备运行不等于用户正在观看。
- 当前产物使用 ad-hoc 签名，升级后系统可能要求重新授权键盘辅助。
