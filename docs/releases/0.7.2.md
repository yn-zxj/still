## 更准确的自动使用计时

- 自动检测新增“前台界面活动”信号，根据前台应用及子进程的短时累计 CPU 时间辅助判断聊天流式输出、静音播放和界面刷新；连续两个采样达到阈值后才继续计时。
- 与 Eye Monitor 的智能模式对照不再只依赖键鼠和媒体播放，减少“画面仍在变化、但手离开键鼠”时的漏记。
- 设置“自动检测”页新增逐分钟活动日志，可从 Finder 直接打开 `~/Library/Logs/Still/activity.jsonl`。
- 日志记录可用状态、计时阶段、疲劳百分比、空闲阈值以及键鼠、媒体和前台进程的空闲秒数；时间去向关闭时不保存前台应用 Bundle ID。
- 前台进程检测不读取窗口标题、网页地址、屏幕画面、文字、音频样本或输入内容，也不请求屏幕录制权限或启用持续屏幕采集提示。

## 对照结果与边界

- Eye Monitor 在 2026-10-31 09:28–13:43 的逐分钟数据记录 200 个活动分钟；旧版息间同窗口约 153 分钟。主要差值来自无键鼠输入但聊天或浏览器仍在刷新内容的时段。
- 今天已发生的旧漏记不会追溯补齐，升级后的同窗口对照才会反映新信号。
- 系统播放音频但无人观看时仍可能延长计时；完全静止、没有进程刷新、媒体或输入的长阅读仍可能在达到空闲阈值后停止累计。

## 验证

- 本地 149 项自动化测试通过，其中前台活动覆盖连续阈值、进程切换和系统不可用清零，诊断日志覆盖不保存应用显示名称及关闭时间去向后的隐私行为。
- `arm64 + x86_64` 通用构建、两个切片最低 macOS 13、严格签名和 OpenPose 模型校验通过。
- 正式发布流水线会分别验证 macOS 14 Apple Silicon 与 Intel 原生启动，并生成 SHA-256 与发布清单。
- 当前产物使用 ad-hoc 签名，升级后系统可能要求重新授权键盘辅助；基础键鼠检测不需要重新授权。
