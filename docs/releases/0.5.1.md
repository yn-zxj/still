## HAPI 一键安装

- 设置页现在可以直接安装或更新 HAPI，不必先使用 npm 或 Homebrew。
- 安装器只读取 HAPI 官方 GitHub Release，按当前芯片选择 Apple Silicon `arm64` 或 Intel `x64` 包。
- 下载完成后使用官方 `checksums.txt` 核对 SHA-256；压缩包只允许包含单个 `hapi` 文件，并安装到当前用户目录。
- 安装后会执行 `hapi --version` 验证版本至少为 0.30.0，成功后自动填写路径并开始同步。
- 安装过程显示检查、下载和安装状态；失败时保留具体原因，可再次重试。
- 已在正常应用中实际安装并验证 HAPI 0.33.3；安装后应用正确显示“HAPI 尚未登录”，没有把未配置 Hub 误报为同步成功。

## 已知边界

- HAPI 二进制由第三方项目 `tiann/hapi` 提供；安装包通过 SHA-256 保证传输内容与官方发布一致，但当前仍不是 Developer ID 签名或 Apple 公证的息间内置组件。
- HAPI 的 Hub 登录与远程机器运行仍需用户按 HAPI 官方流程配置。
