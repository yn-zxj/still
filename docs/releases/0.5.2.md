## 休息提醒

- 视觉提醒窗口打开后立即开始休息倒计时，不再需要先点击“开始休息”。
- 倒计时自然结束后提醒窗口自动关闭。
- 选择推荐锻炼课程后，由课程播放进度接管本次休息；原有休息倒计时结束，课程仍保留暂停、结束和完成状态。
- 系统通知模式保持原有行为，点击通知中的“开始休息”后才进入计时。
- 已在正常应用中实测 5 秒倒计时无需点击即可开始并在结束后自动关闭；选择“眼部疲劳放松”后正确切换到课程 `04:11` 播放进度。

## HAPI

- HAPI 登录只用于读取 Agent 会话和远程机器时间；关闭“Agent 工作时间”或“同步 HAPI”不会影响用眼计时、休息提醒与前台应用统计。
