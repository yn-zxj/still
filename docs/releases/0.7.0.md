## 内部自动检测

- 自动融合键盘、指针、滚轮和前台窗口画面变化，不需要手动切换阅读/视频模式。
- 设置新增“自动检测”卡，展示检测状态，提供键盘辅助与画面检测的系统授权入口；未授权时继续使用基础检测。
- 画面辅助使用 ScreenCaptureKit，低频、低分辨率分析前台窗口；排除息间、桌面、Dock 和菜单栏，过滤光标、小范围动画、单次通知与旧流回调。
- 不录音、不做 OCR、不保存或上传画面；键盘辅助只记活动发生时间，不读取输入内容。
- 锁屏、息屏、休眠和会话离开优先停止累计；明确离开可恢复疲劳，未知状态只暂停判断。旧阅读设置自动停用，历史记录保留。

- 新增简洁提醒：半透明文字横幅，只保留内容、倒计时和关闭按钮。
- 全屏、迷你和简洁提醒同时展示于各显示器；课程只在点击的屏幕播放，返回后恢复多屏提醒。按各屏坐标定位，显示器变化不重新开始计时。
- 修复提醒内点击“结束跟练”后窗口消失的问题；现在停止播放并恢复当前休息倒计时。
- 主动关闭未完成的提醒、课程页或按 Esc 时，本轮记为未休息并按设置的稍后时间再次提醒。
- 状态栏快捷面板重新设计为连续的状态区、紧凑操作区和独立活动曲线；曲线使用 1 pt 绿紫渐变细线、0–24 时每 2 小时刻度、0–100% 每 20% 刻度，并保留未来时段空白。
- “时间去向”统一使用 Lucide 线性趋势图标，替换侧栏、快捷面板、设置卡和空状态中原有的饼图图标。
- “时间去向”的“应用去向”和“类别构成”卡片高度对齐，避免左右底边参差。

本地 151 项自动化通过；原生通用包最低 macOS 13。静态阅读和无人播放仍有歧义，画面变化不能证明有人在看。系统授权及真实采集的验收边界见项目档案，不能用模拟帧测试替代。双屏同步提醒和课程结束恢复已在实机验收；真实拔插和全部 Spaces/独占全屏组合仍待验收。
