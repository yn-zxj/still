## 自行管理休息课程

- 设置新增“休息课程”开关，默认关闭。开启后显示课程库和提醒推荐；关闭保留已有资料。
- 可添加本地视频、HTTPS 视频直链和网页课程，编辑名称、展示时长、封面、简介、准备、身体反应、建议和动作。
- 动作和说明可留空；没有动作时视频占满内容区，不显示缺失提示。
- 支持 JSON 文件、JSON 字符串内容和课程文件夹；导入合并课程，相同 ID 更新，其他课程保留。
- 本地视频复制保存；导入文件重命名避免覆盖。导出备份包含 JSON 和当前课程引用的本地素材，远程资源仅保留链接。
- 安装包不附带第三方课程列表、视频、原文或接口访问凭据；已有个人课程继续留在本机。

## 网页来源

- 网页课程使用独立网页视图播放，支持在浏览器打开；不缓存网页视频、不自动记为完成。
- 识别链接自动获取标题、封面、简介和时长；可预览并修改。通用解析使用可在应用内安装/更新的 yt-dlp，B站有独立适配。
- 优先完整音画 MP4；分离音画/解析失败保留网页播放。原网页用于播放前刷新临时媒体地址。
- 实际站点可能有登录、广告或播放限制；不读取浏览器 Cookie 或保存访问凭据。

本地132项测试通过，普通应用已完成自制3秒本地视频的添加、复制与实际播放检查。使用原生双架构通用包，最低 macOS 13，仍为 ad-hoc 签名。
