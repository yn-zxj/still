## 自行管理休息课程

- 设置新增“休息课程”开关，默认关闭。开启后显示课程库和提醒推荐；关闭保留已有资料。
- 添加课程统一为“本地视频”和“链接导入”：链接框会自动识别视频直链、普通网页或 B 站地址。
- 可编辑名称、展示时长、封面、简介、准备、身体反应、建议和动作；编辑页支持二次确认后删除课程。
- 动作和说明可留空；没有动作时视频占满内容区，不显示缺失提示。
- 支持 JSON 文件、JSON 字符串内容和课程文件夹；导入合并课程，相同 ID 更新，其他课程保留。
- 本地视频复制保存；导入文件重命名避免覆盖。导出备份包含 JSON 和当前课程引用的本地素材，远程资源仅保留链接。
- 安装包不附带第三方课程列表、视频、原文或接口访问凭据；已有个人课程继续留在本机。

## 视频播放

- 原生视频进度条支持点击或拖动跳转；视频区域获得键盘焦点后，`←` / `→` 前后 5 秒，空格播放或暂停。
- 鼠标滚轮继续滚动课程页面，不会意外改变视频进度。跳过的区段不计入连续跟练时间。
- 本地视频与普通直链保持首次在线播放、后台缓存和后续离线播放；网页课程不缓存、不自动记为完成。

## 网页来源

- 网页课程使用独立网页视图播放，支持在浏览器打开；不缓存网页视频、不自动记为完成。
- 识别链接自动获取标题、封面、简介和时长；可预览并修改。通用解析使用可在应用内安装/更新的 yt-dlp，B站有独立适配。
- 优先完整音画 MP4；分离音画/解析失败保留网页播放。原网页用于播放前刷新临时媒体地址。
- 实际站点可能有登录、广告或播放限制；不读取浏览器 Cookie 或保存访问凭据。

## 版本更新

仓库改为公开后，应用直接匿名读取 GitHub Release；设置页不再要求仓库令牌，也不会把 GitHub 凭据写进 Keychain。安装包仍会核对 Release 来源、文件大小和 SHA-256。

本地 133 项测试通过。普通应用已用公开 B 站视频验证标题/封面/简介识别、原生画面播放、点击跳转、方向键前后 5 秒、空格播放/暂停，以及滚轮不改变播放进度；Release 附件审计结果在发布记录中另行说明。使用原生双架构通用包，最低 macOS 13，仍为 ad-hoc 签名。
