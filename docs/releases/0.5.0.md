## 时间去向

- 新增今天、近 7 天和近 28 天的时间去向页面，包含前台应用时间流、类别趋势、应用排行、应用切换与最长停留。
- 时间轴只绘制到当前时刻，不再为尚未发生的时段留空。
- 状态栏快捷面板加入紧凑时间去向卡片，可直接打开完整页面；点击面板外部会立即收起。

## Agent 与 HAPI

- 支持 HAPI 0.30+ 的 `hapi.activity.v1` 报告，汇总本机及其他机器上的 Codex、Claude Code 等 Agent 会话。
- 以 `hapi:<session.id>` 去重，重复同步不会重复计时；等待用户回复的时间和重叠并行会话的墙钟时间按无重复口径计算。
- Agent 历史单独保存 31 天。只保存会话标题、项目路径、机器名称和工作时段，不保存 prompt、回复或代码内容。

## 桌面体验

- 设置中可立即同步 HAPI、选择 `hapi` 可执行文件、恢复自动查找或清除 Agent 历史。
- 支持隐藏 Dock 图标，菜单栏入口、计时和提醒继续运行；可随时恢复 Dock 图标。
- 改进时间去向页和快捷面板的布局、图标、留白与动效。

## 已知边界

- HAPI 需要用户自行安装并登录；本次开发机未安装 `hapi`，真实 Hub 与跨机器会话没有在本机实机验收。
- Agent 时间来自 HAPI 会话元数据，不等同于逐秒 CPU 占用。
- 构建仍使用 ad-hoc 签名，尚未使用 Developer ID 或 Apple 公证。
