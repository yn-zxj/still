## 产品与明确偏好

- 原生 macOS 用眼监控与休息提醒，替代个人订阅软件的核心功能。
- 中文显示名：息间；英文项目名：Still。用户指的是工程/目录用英文，不要求删除中文名。
- 重视 UI 美观、留白、图标与文字间距、较易读的字号和动效。避免重复口号、无用说明。
- 增加休息期间的工位活动：肩颈放松、头前倾相关练习、手腕/手指放松、眼部休息等。
- 课程素材希望风格统一；接受中文真人视频；当前明确用于个人使用。
- 用户手表型号：**OPPO Watch X**。用户确认官方 OPPO 健康课程支持连接该表；尚无 Still 接入验证。
- 用户已要求 GitHub 私有备份，公开与商用分发未获授权。
- 界面验收使用用户当前运行的普通应用；不要每次另建预览应用。只有需要隔离破坏性数据时才使用独立体验实例。
- 菜单栏只显示状态图标与疲劳百分比，不显示倒计时；设置页不再提供两个菜单栏文本开关。

## 课程研究重要结论

详见 [课程与手表研究](COURSES_AND_WATCH.md)。

1. 最初开源健身数据集的“代码许可”与“媒体许可”不同，不能整体作为免费素材使用。
2. Feeel 为步骤式动画，RepDB 免费层为静态图；Pexels 有统一系列但与用户偏好不完全吻合。
3. OPPO 健康至少部分课程使用 Keep 视频。实际见到白底统一演示、中文动作名、次数/秒数、Keep 标识。
4. Root 手机可读 `files/fit_course_video` 以及课程下载索引。视频缓存为分块下载、预分配长度，单看文件大小或首帧不能确认完整性。
5. `okdownload-breakpoint.db` 保存下载 URL、ETag 和分块进度；从已观察课程记录获取 URL 后直接下载成功。
6. 已完整验证 172.013 秒和 769.313 秒两份 1920×1080、H.264 + AAC 视频：直接 URL 下载后全片音视频解码均通过。短片已匹配“3 分钟肩颈舒缓”，长片仍待课名核对。最终以本机验证清单为准。
7. 本轮通过官方 App 的课程目录缓存与只读详情调用匹配并取得15门选定课程；保存原文说明、阶段、重复动作及原始图片/视频地址。13门有180条动作，2门按摩课接口未给动作表；眼部课无禁忌栏，保留null。第三方课程JSON仍在仓库外。
8. 15个视频、81张不同动作图片共96个CDN地址，全部在Mac不带Cookie/Authorization/Referer/应用签名时返回200或206及有效媒体头；这证明当前可直连，不证明永久可用或授权再分发。OPPO列表匿名POST为403，Keep详情匿名GET虽200却空响应，不能作为公开API。详见 [资源接入](RESOURCE_ACCESS.md)。

### 0.3.2 边播边缓存与无动作布局

- 最终交互按用户最新要求：首次直接在线播放，同时后台下载完整视频，无需等待缓存完成。缓存状态位于播放器下方，不遮挡观看；后台缓存失败不阻断在线播放，可单独重试缓存。完整缓存校验通过后，后续及重启应用直接使用本地file URL，缓存完成不切换当前播放器或重置进度。
- 缓存路径`~/Library/Application Support/Still/MediaCache/Videos`，与课程目录分离，重新导入目录不会删除；预览使用独立`Still-UIValidation/MediaCache`。URL+可选预期SHA256作为缓存键，源URL变化产生新条目。完成条目保存实际字节数和SHA256，命中核对版本/来源/文件类型/大小。
- 下载使用URLSession磁盘下载，默认TLS校验、不发送账号Cookie/凭据；拒绝非HTTPS重定向、非200/部分响应、长度不符、摘要不符、不可播放或无视频轨道的文件。暂存校验后原子提交；失败/取消不产生可用条目；同URL缓存任务合并，切课可继续下载，退出取消未完成任务。
- 完整缓存不按时间/容量自动淘汰；课程列表右上角显示视频缓存大小并提供清理。有活动跟练/正在加载时停用清理；清理不删除课程目录、图片、用户导入的原媒体或使用记录。尚未实现断点续传，未缓存完整就退出，下次仍需联网。
- 图片增加独立磁盘缓存`MediaCache/Images`，首次加载后跨重启复用；坏图片回退下载。首次视频加载时展示课程封面，避免长时间黑屏。
- 用户布局要求：actions为空不创建整个动作左栏、不显示占位说明；视频和下方介绍占满内容宽度并保持素材比例。已有动作课程保留原分栏。
